# Data Science Practice

My hands-on learning journey toward becoming an AI engineer.

This repository contains Jupyter notebooks for practicing data exploration,
cleaning, visualization, encoding, scaling, and feature engineering.

## Practice datasets
- Yachts and cruise vessels
- Heart health
- Insurance
- EV battery health

## Tools
Python, NumPy, Pandas, Matplotlib, Seaborn, and scikit-learn.

## Current progress
These notebooks document learning and experimentation with data preparation.
They do not yet include trained prediction models.

## Running the notebooks
Open a notebook in Jupyter and place its required CSV file alongside it.
Some notebooks also import sheryanalysis.
